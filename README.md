# portfolio-spider-man

Fiz um portfólio pro Spider-Man, ele tá precisando de um job agora que os Vingadores esqueceram dele. 🕷️

## Tecnologias

- HTML5 semântico
- CSS3 (Grid, Flexbox, variáveis, media queries)
- JavaScript puro (IntersectionObserver, Web Share API)

## Funcionalidades

- Layout responsivo com menu mobile acessível (fecha com `Esc`, clique fora ou ao escolher um link)
- Header fixo com efeito de vidro ao rolar
- Link do menu destacado conforme a seção visível
- Lazy load das imagens e animações de entrada
- Formulário de contato com validação e mensagem de retorno
- Botão "Curta e compartilhe" usando a Web Share API (ou copia o link)
- Respeita `prefers-reduced-motion`

## Como rodar

Basta abrir o `index.html` no navegador.
